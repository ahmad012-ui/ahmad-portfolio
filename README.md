# Ahmad Rehman — Portfolio V2

A sleek, modern personal portfolio for a Frontend Developer and QA Engineer, built with React and Vite. The design uses a bold monochrome editorial aesthetic with strong typography, smooth navigation, project highlights, and a polished contact experience.

## ✨ Highlights
- Responsive single-page portfolio layout
- Dark monochrome visual design
- Sections for About, Skills, Projects, Experience, and Contact
- Social links and portfolio navigation
- Contact form wired to Formspree
- Clean Vite + React architecture

## 🧩 Tech Stack
- React
- Vite
- CSS
- Lucide Icons
- React Icons

## 🚀 Getting Started

### Install dependencies
```bash
npm install
```

### Run locally
```bash
npm run dev
```

### Production build
```bash
npm run build
```

### Preview production build
```bash
npm run preview
```

## 📦 Deployment
The app builds to the `dist/` folder. Typical Vite deployment settings:
- Build command: `npm run build`
- Publish directory: `dist`
