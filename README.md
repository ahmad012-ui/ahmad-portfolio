# Ahmad Rehman — Portfolio V2

A modern personal portfolio for a Frontend Developer and QA Engineer, built with React and Vite. The site uses a bold monochrome editorial aesthetic with responsive layouts, subtle scroll reveals, an interactive hero background, project cards with detail modals, and a polished contact experience.

## ✨ Highlights

- Responsive single-page portfolio layout
- Dark monochrome visual design
- Smooth section navigation and subtle scroll-reveal animations
- Interactive animated 3D hero background effect
- Sections for About, Skills, Projects, Experience, and Contact
- Interactive project cards with detailed project modals
- Project technology tags and GitHub links
- Social links and portfolio navigation
- Lazy-loaded project preview images
- Accessible keyboard interaction for project cards
- Escape-key and backdrop controls for project modals
- Contact form wired to Formspree

## 🚀 Getting Started

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

### Production build

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## 📦 Deployment

The app builds to the `dist/` folder. Typical Vite deployment settings:

- Build command: `npm run build`
- Publish directory: `dist`
